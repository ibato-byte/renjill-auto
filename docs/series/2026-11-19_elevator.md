## 第1話「気まずい2人」（20秒）
扉が閉まって2人きり → チラッと見て目をそらす → 沈黙（4〜6秒に「・・・。」）→ レンが無意識に耳を左右にゆらし、
何回かに分けて全部の階のボタンを押す → レンが固まる → ジルの無言のツッコミ → 目が合って静止 → 「続きは次回！フォローして待っててね／To be continued! Follow us」

## 第2話「助けようとしたのに、もっと悪くなる」（15秒）
オーナーの絵コンテ（2026-11-17）：
- 0.0〜4.0 チーン！扉が開くが誰もいない → 閉まる → すぐ次の階でチーン！をテンポよく。レンは困り顔、ジルはだんだんあきれ顔
- 4.0〜7.0 ジルがレンの耳とボタンを交互に見る → ひらめく → メガネをクイッ（見せ場）→ 少し得意げに胸を張る
- 7.0〜9.0 ジルがレンの長い両耳を持ち上げて頭の上にまとめる。レンは目を丸くしてされるがまま → ジルは満足して手をはなす
  （うさぎには腕がないので、ジルはレンのうしろに回り、口で耳を1本ずつくわえて上げる）
- 9.0〜10.5 ボヨヨ〜ン！耳が勢いよく戻り、反動で片耳が「開」に当たる → 点灯（ピッ）
- 10.5〜12.0 チーン！扉が開くと正面に新人ポム。ポムはふしぎそうな顔。レンとジルは同時に固まる
- 12.0〜15.0 その構図のまま。「続きは次回！フォローして待っててね／To be continued! Follow us」
- 演出：開閉はテンポよく少し大げさに／反応は段階的に／メガネの仕草が見せ場／耳は布やゴムのようにしなやかに／はね返りはスクワッシュ＆ストレッチとオーバーシュート／耳がボタンに触れる瞬間をはっきり／ポムが出た直後の静止がオチ／カメラは切り替えすぎない
- 効果音：チーン・ウィーン・クイッ・ボヨヨ〜ン・ピッ・チーン。セリフ・説明のテロップは使わない

## 第3話へ引きつぐ最後の状態（第2話の終わり）

## 第3話「解決した…と思ったら」（20秒・最終話）
オーナーの絵コンテ（2026-11-17）：
- 0.0〜4.0 ポムが乗りこむ → 光るボタンと困った2人を見る → レンのたれ耳がボタンのそばにあると気づく → 目がキラッ（ピコーン）
- 4.0〜7.0 ポムが赤いはちまきを外す → レンの耳を頭の上にまとめ、はちまきでキュッと結ぶ → 少し間抜けでかわいいレン。ポムは満足、ジルは笑顔で小さく拍手
- 7.0〜10.0 チーン！1階。レンはうれしそうに目を細め、扉へ向かおうとする（仕事から解放される幸せ）
- 10.0〜14.0 ポムが「！」→ ほおがぷくーっ → 書類がほおから次々に飛び出し（ポン！ポン！ポポポポン！）、レンが書類の山に埋もれる。黄色いネクタイだけが見える → ジルが静かに目をそらす → 無音の一瞬
- 14.0〜20.0 「続きは次回！フォローして待っててね／To be continued! Follow us」
- 作り方のメモ：ポムはレンのうしろ（背中の上）から耳をまとめる（第2話のジルと同じ）。ほおがふくらむ所は、2人のかげにならないようポムが前へぴょんと出る。
  はちまきを外したポムの頭は、はちまきだけ消して形はそのまま。レンが埋もれる・最後の静止はわざとなので、台本の EP.qaAllow で検査を通す
