# 3話連載の企画置き場（docs/series/）

竜さん・オーナーが用意した3話分の企画（テーマ・3話の流れ・各話の台本や絵コンテ・Claude への制作の指示）を、
1つの話につき1ファイルで置く場所。ファイル名は `<最初の月曜の日付>_<話の id>.md`（例 `2026-11-23_elevator.md`）。

## 絵コンテは「動画にする前に」オーナーに見せる（2026-11-20 オーナー）
- **毎週土曜 12:00 までに、次の月・木・土（または木・土・月）の3話の絵コンテを作り、オーナーに見せる。** 担当は予約の「東京うさぎオフィス 来週の絵コンテ（土曜）」。
  形はオーナーの絵コンテと同じ（秒ごとの流れ・演出上の重要事項・効果音）。ここに `<最初の投稿日>_<話の id>.md` で置き、先頭に「オーナーのOK：未」と書く。
- **オーナーのOKが出るまで、動画を作らない。** OKが出たら、予定表の回の `series.storyboard_ok` に OK の日付を入れ、このファイルの先頭を「オーナーのOK：YYYY-MM-DD」にしてから作る。
- `series.storyboard_ok` がない回は `auto/post.py` が出さず、`auto/series.py` が知らせる（3日以内なら不合格）。
- 総見直し（毎日 13:23）と週次PDCA（月曜 7:03）は、ここにある**OK済み**の企画だけを描画・検査・予定表への登録に使う。OKのない企画は描画しない。
- 書き方の決まりは docs/SERIES.md（Part N・前回のあらすじ・次回予告・フォローのテロップ）。
- 絵コンテを置いたら `python3 auto/sbcheck.py`（OK 待ちの絵コンテを点検：尺・冒頭3秒・オチの後のオチ・集中線・「消える」退場・腕が要る動き・前回のあらすじ・フォロー。警告だけ。2026-11-28）。
