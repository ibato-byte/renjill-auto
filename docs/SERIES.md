# 週3本・3話連載の運用方針（2026-11-16 オーナー決定）

レンとジルの短い動画（Instagram・Facebook・YouTube ショート・TikTok・Threads など、短尺の全部）は、
**毎週 月・木・土 の週3本**にし、**1週間の3本で1つの話（3話連載）** が完結する形にする。
作業用BGM（YouTube の長い動画・水・土 20:23）はこの決まりの外で、今までどおり続ける。

## ① 話の作り（3話で1つの話）
- 月＝第1話、木＝第2話、土＝第3話。3本で1つの話が終わる。各話の終わりに「続きが気になる」引きを作る。
- **どの話から見ても分かるようにする**（リールはおすすめから途中の話に出会う人が多い）。
  - 冒頭の一言（表紙の文字と同じ）に「Part 1／2／3」を入れる。
  - 第2話・第3話は、最初の1〜2秒で前回のあらすじを絵で見せる（台本の頭のコメントに `// 前回：` の1行）。
  - 各話の中にも小さなオチを1つ置き、その話だけでも楽しめるようにする。
- **最後のテロップ**：第1話・第2話は次回予告とフォローのお願い（例「続きは次回！フォローして待っててね」）。第3話もフォローのお願い（次の話へつなぐ）。
- 海外（英語圏・中国語圏）にも届くよう、言葉がなくても分かる絵と動きを基本にし、テロップは英語を併記する（今の決まり：英語が主、日本語が従）。
- キャラクターの見た目はアニメのデザインが正（ゲーム・公式サイトと同じ）。

## ② 投稿の頻度
- 毎週 月・木・土 の週3本（1日1本）。ほかの曜日には入れない（`auto/post.py` が出さない）。
- 本数を減らした分、1本ごとの企画・台本・アニメーションの完成度を上げる。

## ③ 作り方
| 段階 | だれが | なにを |
|---|---|---|
| 企画・構成 | 竜さん（ChatGPT は無料プランの範囲で）または週次PDCA（Claude） | テーマ、3話全体の流れ、各話の台本と絵コンテ、Claude への制作の指示。3話まとめて考え、話のつながりをそろえる |
| アニメーション | Claude（総見直し・週次PDCA・竜さんのチャット） | 1話ずつ台本（`rig/ep/<ep>.js`）を作り、描画・検査（`auto/brushup.py`・`auto/qa.py`・`python3 auto/series.py`） |
| 確認 | 竜さん（人の目） | 動き・表情・演出・話の伝わりやすさを1話ずつ確かめ、直す点を Claude に伝える。直して作り直しをくり返す |
| 投稿 | GitHub Actions（`post.yml`） | 予定表（`auto/schedule.json`）の回を、その日の時刻に自動で出す |

- 竜さんやオーナーから3話分の企画・絵コンテが届いた週は、それを最優先で使う（例：エレベーターはオーナーの絵コンテ）。届かない週は、週次PDCAが自分で3話の企画を立てる。
- 予定表の回には `"series": {"id": "<話の id>", "part": 1〜3, "of": 3}` を書く。
- 在庫：1話完結で作ってあった回は `auto/stock.json`（台本は `rig/ep/` に残してある）。3話連載の材料や季節の話の種に使ってよい。そのまま1話完結では出さない。

## ④ 見る数字（4週間続けて見直す）
1. 最後まで見られた割合（平均視聴時間÷長さ）
2. 第1話 → 第2話 → 第3話へ、見る人がどれだけ続いたか（各話の再生数の比）
3. 保存・シェア
4. フォロワー増（特にフォロー率＝フォロー÷リーチ）

初回の見直しは 2026-12-21 ごろ（11/23 の週から4週分）。決まりは数字を見て変えてよい。

## 仕組み（自動の検査）
- `auto/series_policy.json`：曜日・何話で1つか・始まりの日。
- `auto/series.py`：予定表の検査（曜日の外の回・`series` の欄・「Part N」・つづく・次回予告・フォロー・あらすじ・3話そろい）。`epcheck.py` と毎朝の振り返り（`daily_review.py`）が使い、合わなければ総見直しに直す依頼が出る。
- `auto/post.py`：月・木・土の外の回は、予定表に残っていても出さない。
- `auto/cadence.py`：本数は週3本に固定（以前の「週5本→毎日」の自動判定は使わない）。
- テスト：`tests/test_series.py`（本物の予定表に月・木・土の外の回がないことも確かめる）。
