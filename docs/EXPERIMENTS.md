# 毎日の振り返りと「投稿ごとに1つ試す」しくみ（Hub 依頼 #95）

目的：改善を週1回から毎日に。投稿ごとに打ち手を1つだけ変えて、結果を記録し、効いたものを次から標準にする。

## 毎日の流れ（Claude を使わない。GitHub Actions）
| 時刻（日本） | 動くもの | すること |
| --- | --- | --- |
| 6:30 | metrics | 再生・いいね・コメント・シェア・保存・フォロワーを集める（`content/metrics.csv`・`followers.csv`）。続けて `auto/insights.py` が、保存・シェア・リーチ・平均視聴時間・プロフィール訪問・フォロー（リール）、アカウントの1日分、ストーリーズ（返信・タップ・離脱・リンク移動）、Facebook リールの再生・反応を `content/insights.csv` に1指標1行で足す。取れなかったものは理由を空欄の横に書く |
| 6:50 | daily-review | `auto/daily_review.py`：①前の打ち手を評価（標準の回の中央値と比べて良い／同じ／悪い。2割以上の差）②次の未投稿の回に打ち手を1つ割り当て ③目標との差を Hub に出す ④止まっていないか点検（数字が2日続けて取れない・打ち手の記録がない・予定表が7日を切った） |

数字に変化がない日は、記録（`content/daily_log.csv`）だけで終わる。

## 打ち手（1回に変えるのは1変数だけ）
自動で割り当てるもの（予定表の回の `experiment` に書かれる）：
- `thumb_variant`：サムネの文字の位置（A＝上、B＝下）。検査に通らなければ A で出す
- `tag_set`：ハッシュタグの組み合わせ（A／B）
- `cta`：最後の一言（`auto/daily_review.py` の `CTAS`。英語/日本語）
- `slot`：投稿時刻（12:00／18:00／19:00）

Claude（週次PDCA）が文を作って試すもの：つかみ（最初の1秒）、サムネの絵、フック文。回の `experiment` に `{"var":"hook","std":"…","value":"…","why":"…"}` を書き、`content/experiments.csv` に1行足す（状態＝予定）。

## 記録
- `content/experiments.csv`：投稿日・ep・変数・標準・試す値・理由・状態（予定→評価済み）・結果・採用（標準にする／戻す／様子見）
- `content/standards.json`：効いて標準にしたもの
- `content/goal.json`：目標（Instagram フォロワー・期限）。直線で伸びて届きそうなら自動で引き上げる
- `content/daily_log.csv`：毎日の「目標との差」「次に試すこと」「止まっているもの」

## 注意
再生が100台の段階では1本ごとの差は偶然も大きい。結果は「参考値」と書く。「良い」は1回でも標準に入れる（効いたものを次から使うため）が、週次PDCAが毎週「偶然ではないか」を見直し、悪くなっていれば戻す。
