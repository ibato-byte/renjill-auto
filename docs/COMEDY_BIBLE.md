# レンとジル 笑いの教科書（毎週更新）

> 週次PDCAが、ネタを作る前に必ず読み、毎週の最後に「効いた型／効かなかった型」を更新する。月1回、全体を書き直す。
> 他作品の絵・キャラ・音は写さない。学ぶのは「なぜ笑えるか」の構造だけ。数字は `content/metrics.csv` と計測シートの実測だけを書く（捏造しない）。
> 作成: 2026-10-22（依頼 #34）。最初の版は笑いの一般的な型の整理が中心で、「他作品の調査」「自分たちの数字との突き合わせ」は第5章・第6章に毎週足していく（初回は未記入）。

## 1. 笑いの型（セリフなしで使えるもの）
| 型 | しくみ | レンとジルでの使い方 | 注意 |
|---|---|---|---|
| 三段エスカレーション（ルール・オブ・スリー） | 1回目で型を見せ、2回目で確信させ、3回目で外す。回数が増えるほど笑いが大きくなる | 課長の同じ動作を3回、3回目だけ結果が裏切る | 3回とも具体的に。間を空けすぎると気づかれて冷める |
| ずらし（裏切り） | 観る人の予想を、状況の中で自然に外す | 「頼れる課長」の絵から入って、ささいなことで崩れる | 外し方が唐突すぎると「意味不明」になる。理由が絵で分かること |
| 天丼 | 同じ流れをもう一度、少し変えて見せる | 前半のネタを後半で別の形で繰り返す | 2回目に変化がないと飽きる |
| 溜めとオチ | オチの直前に一瞬の静止（間） | オチ前に0.5秒の静止＋ジルの視線 | 長すぎると離脱。短い動画では0.3〜0.7秒 |
| リアクション | 起きたことより、それを見た人の顔で笑う | ジルのあきれ顔・無言のツッコミ（スタンプにしたい顔） | 毎回同じ顔にならないよう3種類を回す |
| オチの後のオチ | 終わったと思わせて、もう一段 | 最後の1カットで小さな追い打ち | 本編を伸ばしすぎない（30秒未満） |
| ループ | 終わりが冒頭につながり、2周目が見たくなる | 終わり→冒頭が自然につながる版を維持 | つなぎ目の唐突さに注意 |
| 代弁（あるある） | 言いたくても言えないことを、動物が代わりにやる | 会議・月曜・締め切り・定時 | 特定の人や会社が分かる表現は避ける |
| 単純な欲求 | 「眠い」「食べたい」「帰りたい」だけで動かす | 課長の望みは1回1つ | 背景説明を足さない |

## 2. 作る前の審査基準
- 採点（各5点）：①1秒目のつかみ ②三段の上がり方 ③オチの意外さ ④海外で伝わるか ⑤送りたくなるあるある度 ⑥レンとジルらしさ ⑦**新しさ**（直近8回と同じ型・同じ舞台・同じオチでないか）。
- 審査役（Agent で別々に立てる。意図は渡さず、台本と絵コンテだけ見せる）：日本の会社員／海外の視聴者／お笑い作家／初めて見る人。
- 基準点：4役の平均が各項目3.5以上、かつ合計の平均が27/35以上。届かないネタは出さない。

## 3. 絶対に外さないこと
最初の1秒で状況／セリフなしで伝わる／遊び（ゲーム）は1本に1つ／関係性（ジルが課長をどう思っているか）が1カットで分かる／瞬間カット禁止。
