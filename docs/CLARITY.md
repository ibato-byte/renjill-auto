# 分かりやすさの決まり（CLARITY）

2026-11 オーナーから「動画が意味不明なことが多い。セリフもないので、そこで視聴者が離れる」と指摘。新しい回はすべて、投稿の予定に入れる前にこの決まりで確かめる。

## 1. 作る前（台本）
- 1話で伝えることは「状況 → ひっくり返し → オチ」の3つだけ。4つ目の小ネタは、分かりやすくならないなら削る。
- それぞれを「絵1枚で言える」形にする（例：時計17:59＋帰り支度のジル／書類を抱えた上司／18:00にジルが走って帰る）。
- 説明に手順が要るネタ（メールの宛先・システムの操作など）は使わない。
- キャラはしゃべらない（セリフ・吹き出しの文字なし）。そのかわり、短い字幕（英＋日）を最大2回出す：状況（冒頭の一言）とオチ。
- 冒頭の一言（rig/pace.js の hook）は「誰が・どんな状況か」を書く。ラベルだけ（例：TAX FORMS）にしない → BOSS VS. TAX FORMS／年末調整の書類を前にした上司。
- 英語は大きく1行（短く）、日本語は小さく1行。時刻は24時間表示で、動画の時計と同じ数字にする（tests/test_textcheck.py が確かめる）。

## 2. 作ったあと（目で確かめる）
- 音を消して、8コマのコンタクトシート（動画を8等分したコマ）だけを見る。
- 話を知らない人（または台本を見ていない Claude）が、コマだけで「状況」と「オチ」を1文ずつ言えるか。言えなければ直す。
- 消える・倒れるなど「何が起きたか」が分かりにくい動きは、別の分かりやすい動き（走って帰る・目が回る印）に替える。
- オチの絵は 0.8 秒以上見せる。小物（牧草など）は顔と同じくらい目立つ大きさにする。
- 字幕・顔は画面の上下（各SNSのボタン・キャプションに隠れる所）に置かない。字幕は高さ 1380px 前後。

## 3. 投稿後
- 冒頭2秒で離れた割合（YouTube の「スワイプされた割合」・TikTok の視聴維持）を毎週見る。悪かった回は、どの決まりを守れていなかったかをこのファイルの下に書き足す。
