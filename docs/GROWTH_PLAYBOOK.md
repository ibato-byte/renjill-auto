## 0. 一番大事な3つ（毎回これだけは守る）
1. **最初の1秒で状況、3秒で「続きが見たい」**。IGは最初の3秒の維持率で配信先が決まる（目安60%以上）。1コマ目からキャラが動作中であること。タイトルカード禁止。
2. **送りたくなる＝あるある**。IG/TikTokとも「DMで送られた数」「保存」が「いいね」より強い。「これ課長じゃん」「月曜の私」と誰かに送りたくなる職場あるあるを軸にする。
3. **ループして2周目が見たくなる終わり方**。総再生時間と再視聴が上位シグナル。オチの後に0.5〜1秒で冒頭に戻れる絵にする（既存の loop 版はこの方針で維持）。

## 2. 伸びている似た作品から学んだこと
- **ちいかわ／おぱんちゅうさぎ／スンスン**：かわいいのに不憫（「不憫かわいい」）、言葉が少ない、独自の世界観、ファンが真似して二次創作できる余白 → 伸びた後にグッズ・コラボ・アニメ化で収益化。
  - モチとユズへの当てはめ：課長（モチ）の「がんばってるのに報われない」を毎回1つ。ユズの無言のツッコミ顔を「スタンプにしたい顔」として固定ポーズ化。
- **テイコウペンギン**（職場あるあるのショートアニメで大きく成長）：会社員の共感、短い尺、シリーズ化、複数SNS同時展開。
  - 当てはめ：「月曜」「会議」「経費」「締切」「定時」など、毎週カレンダーに合わせたあるあるを並べる。
- **3人の関係（2026-11 から）**：課長モチ・部下ユズに、新人クリが加わった（連載「上司とエレベーター」「金のチモシー」）。新人が場をかき回し、ユズが正論で止め、課長が最後に一番やらかす、の順にすると3話の山が作りやすい。
- **セリフなし作品（海外向けの無言アニメ）**：言語に依存しない → 海外のおすすめにも乗る。サムネとキャプションは英語先頭＋日本語で両方拾う（現行方針どおり）。

## 7. モデルの実物のうさぎ（方向性を変えるときの参照元）
- 写真の場所：Shotaさんの Google フォトのアルバム「れんとじる」（本人のアカウントでのみ閲覧。リンクはここには書かない）。
- モチ（課長）＝大きめのホーランドロップ。垂れ耳で、耳は体より一段濃いグレーがかった茶色。毛がふわふわで量が多く、換毛期は頭の上が綿あめのように盛り上がる。どっしり座る。

### 目標（らぶいーず級＝SNS合計100万人）までの道のり
1. **〜1,000人（今〜12月）**：週3本の3話連載（11/16 オーナー決定。それまでの毎日投稿から切りかえ）、ユズの「正論」をもっと前に出す（らぶいーずの「代弁」にあたる部分）。Threads を自動で追加済み（X は有料 API を使わない方針のため自動投稿しない・2026-10-22）。LINEスタンプ申請。
2. **〜1万人（〜2027春）**：反応の良いシリーズを固定し、2匹の関係性（モチはユズに甘い／ユズは口は悪いが課長を見捨てない）を毎回1カットは見せる。ファンが真似できる「決めポーズ」を作る。
3. **〜10万人**：グッズ（受注生産）、企業コラボ。商標を取っておく。
4. **100万人**：書籍・プライズ・アニメ化の打診が来る段階。

### いま決めたこと（2026-10-20。投稿本数は 2026-11-16 に週3本の連載へ変更済み）
- **投稿本数を週3→平日毎日5本**（11/16 まで）（11/2の週から。月曜タスクが5本作る。品質が足りない週は4本に戻してよい）。理由：同じジャンルの成功例が毎日投稿で、初期は本数が最大の変数。
- **らぶいーず方式の「関係性」を台本ルールに追加**：毎回、ユズが課長をどう思っているかが1カットでわかる（あきれる／助ける／照れる）。
- **「代弁」の型**：ユズの正論は「会社員が言いたいけど言えないこと」を選ぶ（例：「それ会議じゃなくてメールでよくないですか」）。セリフなしのままサムネの英語・日本語フックで言う。
- **やしゅし式の画面**：人気回ほど「1匹を大きく・背景シンプル・動きは1つ」。サムネもこれに寄せる。
