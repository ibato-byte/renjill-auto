# レンとジル 成長プレイブック（自動更新）

> このファイルは「いま一番伸びやすいやり方」を1か所にまとめたものです。
> 毎週日曜の「成長リサーチ」タスクが調べ直して書き換え、週次PDCAはここを読んでネタ・サムネ・キャプションを決めます。
> 最終更新: 2026-10-20（初版・手動リサーチ）

## 0. 一番大事な3つ（毎回これだけは守る）
1. **最初の1秒で状況、3秒で「続きが見たい」**。IGは最初の3秒の維持率で配信先が決まる（目安60%以上）。1コマ目からキャラが動作中であること。タイトルカード禁止。
2. **送りたくなる＝あるある**。IG/TikTokとも「DMで送られた数」「保存」が「いいね」より強い。「これ課長じゃん」「月曜の私」と誰かに送りたくなる職場あるあるを軸にする。
3. **ループして2周目が見たくなる終わり方**。総再生時間と再視聴が上位シグナル。オチの後に0.5〜1秒で冒頭に戻れる絵にする（既存の loop 版はこの方針で維持）。

## 2. 伸びている似た作品から学んだこと
- **ちいかわ／おぱんちゅうさぎ／スンスン**：かわいいのに不憫（「不憫かわいい」）、言葉が少ない、独自の世界観、ファンが真似して二次創作できる余白 → 伸びた後にグッズ・コラボ・アニメ化で収益化。
  - レンとジルへの当てはめ：課長（レン）の「がんばってるのに報われない」を毎回1つ。ジルの無言のツッコミ顔を「スタンプにしたい顔」として固定ポーズ化。
- **テイコウペンギン**（職場あるあるのショートアニメで大きく成長）：会社員の共感、短い尺、シリーズ化、複数SNS同時展開。
  - 当てはめ：「月曜」「会議」「経費」「締切」「定時」など、毎週カレンダーに合わせたあるあるを並べる。
- **セリフなし作品（海外向けの無言アニメ）**：言語に依存しない → 海外のおすすめにも乗る。サムネとキャプションは英語先頭＋日本語で両方拾う（現行方針どおり）。

## 3. 運用ルール（週次PDCAが毎週守る）
- 尺：本編 18〜28秒（30秒未満）。loop版は終わり→冒頭が自然につながること。
- ネタ配分：課長のあるある 60% ／ ジルの正論 25% ／ 季節・時事（祝日、決算期、ボーナス、年末進行など）15%。
- シリーズ：「課長のあるある」「ジルの正論」をシリーズ名として各SNSの再生リスト・ハイライトに固定。
- キャプション：1行目に英語の一言フック、2行目に日本語のあるある一言、3行目に「送りたい人をタグして」系の送信を促す一言、最後にハッシュタグ3〜5個（#職場あるある #うさぎ #会社員あるある #bunny #officehumor から回ごとに選ぶ）。
- コメント：投稿後に1件、キャラ目線の固定コメント（例「課長は今日も定時に全力です」）。
- 投稿頻度：週3本（IG/TikTok/YouTube同時）。数字が良ければ週4へ。
- 新しい型は必ず IG トライアルリールで先に試す（手動。週次メールで依頼）。
- 他SNSへの転載はウォーターマーク無しのマスター動画から（現行の自動書き出しで満たしている）。

## 4. 数字の見方（週次PDCAの判定基準）
| 指標 | 良い | 普通 | 見直し |
|---|---|---|---|
| IG 3秒維持率 | 60%以上 | 45〜60% | 45%未満 → 冒頭を作り直す |
| IG 送信数/リーチ | 1%以上 | 0.3〜1% | 0.3%未満 → あるある度が弱い |
| TikTok 完走率 | 40%以上 | 25〜40% | 25%未満 → 尺を短く |
| YT 見た割合（vs スワイプ） | 70%以上 | 55〜70% | 55%未満 → サムネ/冒頭 |
| フォロワー増/週 | +300以上 | +50〜300 | +50未満 → ネタ配分を変える |

## 5. 自動で見直す仕組み
- 毎週日曜（夜）：「成長リサーチ」タスクがネット・各SNSの公式発表・似たアカウントを調べ、このファイルの1〜4を書き換える。変えた点は末尾の「変更履歴」に1行ずつ残す。
- 毎週月曜：週次PDCAがこのファイルを読み、次週4本のネタ・サムネ・キャプションに反映。
- 有料サービスが必要と判断した場合は、使わずにメールで相談（件名に【判断が必要】）。
